# Aarav Hyprland

A portable Arch Linux Hyprland desktop built from scratch.

## Project status

This repository is currently being refactored from a working desktop
configuration into a portable installer supporting:

- NVIDIA, AMD, and Intel graphics
- Desktop and laptop systems
- Battery, backlight, and touchpad detection
- UWSM-managed Hyprland sessions
- KDE Plasma coexistence
- Dynamic Matugen colors
- Waybar, SwayNC, SwayOSD, Hyprlock, Hypridle, and Quickshell
- Manual Gaming Mode
- Health checks, snapshots, and recovery

The repository remains private until the portable installer has been tested
on both the primary desktop and an Arch Linux laptop.
